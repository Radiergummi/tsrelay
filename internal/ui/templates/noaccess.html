{{if .Roles}}Your grants give you the {{join .Roles ", "}} role, but not receiver, which{{else}}Your tailnet policy grants you no access to this relay. The receiver role{{end}} lets you create hooks and receive callbacks.

A tailnet admin can add a grant like this to the policy file:

"grants": [
  {
    "src": ["{{.V.Me.Login}}"],
    "dst": ["tag:tsrelay"],
    "ip":  ["tcp:443"],
    "app": { "{{.Cap}}": [{ "roles": ["receiver"] }] }
  }
]

Use autogroup:member as the source to let every member receive callbacks. The relay reads your grants again on every request.
